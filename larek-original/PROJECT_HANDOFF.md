# Ларёк 1992 — Полный бэкап проекта (Build 232)

Этот архив содержит **всю игру целиком** для продолжения разработки в новом чате или на другом аккаунте без потерь.

## Содержимое архива
- `apk/larek-build232.apk` — полная подписанная сборка Build 232 (`com.larek.game`), внутри которой лежат Android-оболочка (`AndroidManifest.xml`, `classes.dex`, `res/`), все 3D-модели (`assets/assets/models/*.glb`, уже оптимизированы), текстуры (`assets/assets/tex/*`), аудио (`assets/assets/audio/*`) и исходники (`assets/js/*`).
- `source/` — распакованные исходники (`index.html`, `css/`, все 13 ES-модулей `js/*.js`) для быстрого чтения и редактирования.
- `build_tools/build_apk.py` — автономный Python-скрипт пересборки и v1+v2 подписи обоих APK (`com.larek.game` и параллельный `com.larek.gam2`).
- `build_tools/apk_signer_lib.py` — библиотека чистой Python v1+v2 APK-подписи.
- `build_tools/larek_release_key.pem` и `build_tools/larek_release_cert.der` — релизный ключ подписи (серийный номер `19920063`). **Храните архив приватно**, этот ключ нужен, чтобы новые сборки ставились поверх старой без потери сохранений.

## Критические правила движка (проверено на Mali-G78)
1. **НЕ включать `precision: 'mediump'` в `WebGLRenderer`** — на Mali-G78 вызывает 16-битный джиттер вершин (эффект PS1) на мировых координатах `(48, 82)`. Всегда держать `precision: 'highp'`.
2. **НЕ вызывать `ImageBitmap.close()` для текстур Three.js** — при повторной загрузке в GPU текстуры становятся чёрными.
3. **НЕ сжимать `normalTexture` / `metallicRoughnessTexture` / `occlusionTexture` в `.glb`** — оптимизировать только `baseColorTexture`.
4. **Пути внутри APK:** Three.js `assets/models/<name>.glb` резолвится в `assets/assets/models/<name>.glb` внутри APK; JS-модули лежат в `assets/js/*.js`.

## Текущее состояние (Build 232)
- Перенесена гиря 24 кг в спальню квартиры (`45.25, 2.654, 82.85`, миграция `aptKbMove228`), высота пола учитывается в `kbPlace`.
- Реалистичная физика ударов и пинков по мебели (`life.js`: `settleBoxPose`, `strikeItem`, `ragdoll` — стулья, кресла, табуретки, столики опрокидываются на бок/спинку и скользят).
- Настольная лампа в квартире переведена в полноценный физический предмет `desk_lamp` (вкл/выкл, перенос, динамический свет следует за лампой, миграция `aptDeskLampItem228`).
- Оптимизация FPS: зеркало в ванной рендерится только когда игрок смотрит на него (`224x288`, каждый 3-й кадр); ~130 книг квартиры объединены в один `THREE.InstancedMesh`; добавлены `THREE.LOD` для `tv_rubin`, `radio` (со слиянием 17 примитивов), `alarm_vityaz`, `chair_item`, `chair_old`; на минимальном пресете анизотропия снижена до `1x`.
- Также реализовано: выбор API (Vulkan 1.4 / OpenGL ES 3.2 / Metal) с автодетектом, 4-вкладочные настройки (Графика / Геймплей / Звук / Система), полые фарфоровые чашки и тарелки 1989 г., прозрачный вращаемый 3D-будильник «Витязь» лицом к окну, TV «Рубин» (2 кнопки при выкл / +канал при вкл), динамический солнечный свет из окон, исправленный каркас/матрас кровати и дверцы комода.

## Как пересобрать APK из этого архива
```bash
python3 build_tools/build_apk.py --base apk/larek-build232.apk --src source --key build_tools/larek_release_key.pem --cert build_tools/larek_release_cert.der --build 230 --out ./out
```

- **Build 232:** Интегрирован детализированный и оптимизированный 3D-холодильник «ЗИЛ-Москва КХ-240» (`source/js/fridge_zil.js` + 3 состаренные фотографии `source/tex/fridge/`) в кухню квартиры и в ларёк.
