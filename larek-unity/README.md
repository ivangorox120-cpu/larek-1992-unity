# Ларёк 1992 — полный перенос на Unity

Проект переноса игры «Ларёк 1992» (Build 232) с Three.js/HTML на Unity 2022.3.62f1.
Оригинал включён в репозиторий как справочник в `../larek-original/`, его ресурсы скопированы в
`Assets/StreamingAssets/Game/` (81 GLB, 62 текстуры, 27 аудио, 10 видео, 25 иконок, 5 шрифтов).

## Состав

| Ассембли | Что реализует |
|---|---|
| `Larek.Economy` | 15 товаров, стартовые/оптовые/розничные цены, средняя стоимость, торговые операции, снимок состояния |
| `Larek.Interactions` | домофон (код 1992 на 6 с), кнопка «ВЫХОД», английский замок квартиры, досягаемость ручек ≤1 м |
| `Larek.Save` | версионированное сохранение экономики, позиции и состояния дверей |
| `Larek.Gameplay` | `GameSession`, инвентарь, уведомления (2,2 с), диалоги, цикл дня и погоды, админ-панель `larek1992`, прогресс, bootstrap сохранений |
| `Larek.World` | каталог 81 модели, 8 остановок, постройка ларька/подъезда/квартиры/лестницы, свет, LOD, зеркало, погода, 3D-звук, точки взаимодействий |
| `Larek.Systems` | автобус ПАЗ-652 с заездными карманами, NPC, ружьё, гитара/руки, домофон, холодильник ЗИЛ, ragdoll, верёвка/люк, звук, клавиши |
| `Larek.UI` | HUD, подсказки, торговая панель, диалоги, блокнот, газеты, модалки, 4 вкладки настроек, админ-панель, сенсорное управление |
| `Larek.Porting` | карта покрытия всех 28 записей реестра механик M01–M90 |

GLB загружаются во время исполнения через рефлексивный адаптер UnityGLTF; если пакет недоступен,
используются примитивы-заглушки. save file: `Application.persistentDataPath/larek1992.sav` + `larek1992.extras`.

## Проверка

- Локально без Unity Editor прогнана компиляция всей чистой C#-логики и **37 проверок** ( economy, save, gameplay, transport, phone, weapon, hand, fridge, controls, audio, ragdoll ).
- В Unity Test Runner (EditMode) лежат NUnit-тесты для всех ассембли, включая `PortCoverageTests`.
- GitHub Actions `Unity test and build` запускает EditMode-тесты и собирает APK (`Larek/Build Full Game`, `com.larek.game`, version 232). Для CI нужны секреты `UNITY_LICENSE`, `UNITY_EMAIL`, `UNITY_PASSWORD`.

## Ограничение

Визуальное совпадение с WebGL-оригиналом, физика Mali-G78 и подпись APK требуют запуска на целевом устройстве
и наличия Unity Editor/лицензии. В среде разработки редактора нет, поэтому финальная сборка проверяется только в CI.
Приватного ключа подписи в архиве нет — доступен только публичный сертификат.

Права на медиа оригинала и лицензии приведены в `../CREDITS.md`.
