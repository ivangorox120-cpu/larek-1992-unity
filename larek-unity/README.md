# Ларёк 1992 — перенос на Unity

Проект переноса оригинальной игры «Ларёк 1992» (Build 232) с Three.js/HTML на Unity.
**Это незавершённый проект, а не готовая игра или сборка APK.**

Оригинал лежит в `../larek-original/` и включён в репозиторий как справочник: 14 JS-модулей,
GLB-модели, текстуры, аудио, видео, `MECHANICS.md` и `PROJECT_HANDOFF.md`.

## Что реализовано

- Каркас Unity 2022.3.62f1, packages manifest, редакторный билд Android-прототипа (`Larek/Build Android Prototype`).
- Черновой прототип сцены: геометрия ларька, камера, сенсорное перемещение/обзор и простой UI (`Assets/Scripts/Prototype`).
- Экономика из `js/game.js`: 15 товаров, стартовые цены, оптовые/розничные цены, средняя закупочная стоимость, состояние дня/денег/долга (`Assets/Scripts/Economy`).
- Торговые операции: закупка оптом (включая оптовку с остановки) и продажа покупателю с проверкой остатков и денег (`Assets/Scripts/Economy/Trading.cs`).
- Версионированное текстовое сохранение: экономика, позиция игрока, состояние дверей; запись и чтение через `SaveRepository` (`Assets/Scripts/Saving`).
- Чистые модели дверей подъезда/квартиры по реестру механик: код 1992 на 6 секунд, кнопка «ВЫХОД», ключ снаружи (`Assets/Scripts/Interactions`).
- Редакторные тесты NUnit для экономики, торговли, сохранений и дверей (`Assets/Tests/Editor`).
- GitHub Actions: `Android prototype` (запуск вручную, game-ci/unity-builder).

## Что не сделано

Сцены и 3D-мир оригинала, импорт GLB, настоящий интерфейс, диалоги и NPC, транспорт, предметы,
погода, звук, видео, сохранения оригинала и большая часть механик из `MECHANICS.md`.
Сгенерированный прототип — не перенесённый мир. Три стартовые упаковки товаров ещё не в модели.

## Проверка и сборка

Локально нужен Unity Editor 2022.3.62f1 с модулем Android Build Support. Тесты запускаются в Unity Test Runner
(EditMode). В CI workflow ожидает секреты `UNITY_LICENSE`, `UNITY_EMAIL`, `UNITY_PASSWORD`; без них сборка не пройдёт.

## Источники и лицензии

Оригинал и медиа-ассеты включены только для разработки. `THREE-LICENSE.txt` хранит лицензию Three.js.
Права на текстуры, аудио и видео оригинала требуют отдельной проверки перед публичным распространением сборки.
Приватный ключ подписи APK в архиве отсутствует: в нём есть только публичный сертификат и скрипт, ожидающий `.pem`.
